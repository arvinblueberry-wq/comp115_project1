# comp115_project1
A mountain cabin landscape created using Python Turtle
Description:
For my first project, I used Python Turtle to create a mountain cabin drawing. I drew mountains, snow, trees, a lake, and a wooden cabin. I used different shapes and colours to make the picture.
What I Used:
- Python Turtle for drawing
- Functions to create different shapes
- For loops to avoid repeating code
- Variables to change the size and position of shapes
How to Run:
1. Download the proje.py file.
2. Open the file in VS Code.
3. Run the Python code.
4. A new window will open showing the drawing.
